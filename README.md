# Task 19: Filter Dataset Records with Pandas

This project demonstrates how to filter records from a dataset using single and multiple conditions with the Pandas library in Python.

## 📌 Objectives
- Retrieve relevant records from a dataset using boolean conditions.
- Practice combining multiple conditions using `&` (AND) and `|` (OR) operators.
- Validate and inspect filtered DataFrames by verifying the resulting row counts.

---

## 🛠️ Tools & Technologies
- **Language:** Python 3.x
- **Libraries:** Pandas, Jupyter / IPykernel
- **Environment:** Visual Studio Code (VS Code)
